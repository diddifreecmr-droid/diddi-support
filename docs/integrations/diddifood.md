# Intégration DiddiFood

Statut : `implemented` pour le contrat `diddi.context.v1`, activation
`blocked` tant que le connecteur réseau n'est pas fourni par environnement.

DiddiSupport interroge `diddifood` pour `order` avec le scope
`diddifood:support-context:read`. DiddiFood reste propriétaire du statut,
des montants et des données sensibles.
