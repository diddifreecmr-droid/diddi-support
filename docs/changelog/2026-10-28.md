# 2026-10-28 — Dossiers généraux DiddiComms

Ce changelog décrit l'alignement du contrat interne DiddiComms ↔ DiddiSupport.

- Les dossiers généraux sans ressource métier sont désormais acceptés par
  DiddiSupport lorsqu'ils sont créés par DiddiComms.
- Les références métier partielles retournent
  `SUPPORT_RESOURCE_REFERENCE_INCOMPLETE`.
- La réponse de création conserve les champs historiques et ajoute `case_id` et
  `created_at`.
- La migration `0008_general_support_cases.sql` rend les références métier
  nullable pour les dossiers généraux.
- La version déployée doit encore être validée par build Docker et par les tests
  staging DiddiComms.
