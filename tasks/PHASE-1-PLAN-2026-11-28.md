# Plan P1 — Corrélation `X-Request-ID`

Source : `IMPLEMENTATION_PLAN_2026-11-28_CORRELATION_BACKOFFICE_AUTH.md`.

## Sous-lots

- P1-A : middleware global de réutilisation/génération et propagation du header.
- P1-B : tests contractuels des réponses normales et d'erreur.

## Critères

- Toute réponse HTTP vérifiée porte `X-Request-ID`.
- Un ID fourni est conservé ; un ID absent est un UUID v4.
- Les handlers existants reçoivent l'ID généré comme header de requête.
